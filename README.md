# VeloDrive

Premium car rental platform built with Next.js, Better Auth, MongoDB, and a responsive booking-first UI.

Live Site: `Add your deployed client URL here`

## Features

- Browse available and unavailable cars with search by name and car-type filtering.
- Secure authentication with email/password and Google sign-in.
- Private flows for adding cars, viewing bookings, and managing owner listings.
- Detailed vehicle pages with booking controls, driver preference, and special notes.
- Owner dashboard with update and delete actions for listed cars.
- Responsive interface with custom toast messages, loading states, and a custom 404 page.

## Tech Stack

- Next.js 16 App Router
- React 19
- Tailwind CSS 4
- Better Auth
- MongoDB
- HeroUI

## Local Setup

```bash
npm install
npm run dev
```

Create a `.env` file with your database, auth, and public app/API URLs before running locally.
